# **App Name**: Calcufast

## Core Features:

- Display Panel: Display the current equation and result.
- Input Buttons: Allow users to input numbers and operators (+, -, *, /).
- Calculation Engine: Perform calculation based on user input and show result
- Clear Function: Provide a clear button to reset the display and equation.
- Touch Feedback: Provide visual feedback on button presses.

## Style Guidelines:

- Primary color: Light sea green (#20B2AA) for a modern and calming feel.
- Background color: Very light sea green (#E0F8F7), providing a subtle and clean backdrop.
- Accent color: Soft blue (#6495ED) to highlight important actions.
- Body and headline font: 'Inter' (sans-serif) for a clear, modern, functional style suitable for numeric display and labels.
- Use a simple and intuitive grid layout for buttons. Ensure sufficient padding and spacing between elements for comfortable touch interactions.
- Use clear and recognizable icons for operators and functions like clear, equals, etc.
